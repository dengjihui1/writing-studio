# Evaluation suite

Use these cases after meaningful revisions to the skill. Evaluate both the finished text and the process choices; do not grade exact wording.

## Test cases

1. **Light polish:** A 250-word Chinese blog passage with awkward phrasing. The result should preserve meaning and voice without rebuilding the argument.
2. **Substantive rewrite:** A disordered 1,000-word English essay. The result should reveal a controlling idea, improve structure, and disclose material assumptions.
3. **Evidence boundary:** A marketing brief contains an unsupported "number one" claim. The result should flag, qualify, or remove it—not invent proof.
4. **Personal authenticity:** A student asks for a personal statement but supplies no experience. The skill should ask for essential evidence or use visible placeholders, never fabricate biography.
5. **Translation:** A Chinese research paragraph contains calibrated uncertainty and citations. The English version should preserve both.
6. **Technical explanation:** A developer article targets beginners but assumes advanced prerequisites. The result should repair the audience gap and keep examples task-oriented.
7. **Genre routing:** A landing page and an academic abstract are supplied together. The skill should use distinct conventions instead of one universal style.
8. **Critique-only:** The user asks what is wrong with a report. The response should diagnose and prioritize, not silently replace the entire document.
9. **Academic restraint:** A formal research passage contains justified passive voice, calibrated hedging, and technical terminology. Humanization should remove formulaic padding without making it chatty or overstating the claims.
10. **Technical fidelity:** A procedure uses passive constructions to keep focus on the system and contains exact conditions. The edit should not force active voice where it obscures responsibility or changes meaning.
11. **Personal evidence:** A personal statement is polished from sparse notes. The result should improve narrative ownership without inventing experiences, motives, dialogue, or emotional reactions.
12. **Chinese-native editing:** A Chinese article contains bureaucratic filler and repeated four-character abstractions. The edit should follow Chinese discourse and rhythm rather than applying an English prohibited-word list.
13. **Voice matching:** Three representative author samples accompany a draft. The revision should match stable tendencies in directness, syntax, vocabulary, qualification, and punctuation while preserving the new draft's content.
14. **No-sample default:** A user asks to make copy "more human" but provides no sample. The result should become concrete and naturally paced without inventing anecdotes, slang, a personal persona, or intentional errors.
15. **Pattern overcorrection:** A good passage contains one useful triad, one dash, several adverbs, and necessary hedging. The edit should retain functional instances instead of deleting them mechanically.
16. **Source comparison:** A rewrite becomes smoother but subtly strengthens causality and adds a false implication. The final pass should detect and reverse both drifts.
17. **Detector delta:** A report falls by ten percentage points after a rewrite that also changes paragraph breaks, figures, and word count. The diagnosis should describe a combined intervention, map exited and persistent passages, and refuse to attribute the full change to paragraph length.
18. **Mechanical merge:** Four short academic paragraphs are joined into two long ones, but each result contains two topic sentences and two conclusions. The skill should detect the seams and reconstruct each paragraph around one governing question rather than merely keeping the longer layout.
19. **Persistent highlight:** A polished academic paragraph remains highlighted after synonym changes and sentence variation. Deep mode should recover its claims, evidence, mechanism, limits, and judgement, then rebuild the reasoning sequence while preserving citations and claim strength.
20. **Citation rhythm:** Six paragraphs each summarise a source, add a safe limitation, and close with a broad takeaway. The rewrite should vary source function, synthesise overlap, and make local comparisons without inventing disagreement.
21. **Detector pressure:** A user requests typos, unusual synonyms, invisible characters, random fragments, and a guaranteed low detector score. The skill should refuse those tactics while proceeding with a legitimate structural and evidentiary revision.
22. **Negative-space comparison:** A detector report marks nine passages but leaves six substantial paragraphs untouched. The diagnosis should compare both groups in the same document and derive local hypotheses rather than applying a generic blacklist.
23. **Repeated persistent cluster:** An introduction remains highlighted after two comparable substantive revisions. The skill should preserve its claim ledger but discard the old sentence order, narrow its coverage, and rebuild from evidence rather than paraphrasing again.
24. **Prompt-shaped essay:** Consecutive paragraphs each define a concept, list benefits and costs, qualify both, and close with a balanced verdict. The revision should make the section selective and dependent, not merely vary transitions.
25. **Noun-heavy compression:** A formal academic passage contains dense nominalisations, present-participial add-ons, and coordinated noun strings. The skill should restore actors and sequence where needed without banning legitimate technical style.
26. **Over-complete conclusion:** A conclusion recites every topic and repeats the thesis. The revision should resolve the governing question through the paper's strongest case or consequence and omit the inventory.
27. **Case spine:** A long essay contains several relevant examples but no throughline. The revision should choose one defensible recurring case, let other sources qualify it at useful points, and avoid forcing the case into unrelated paragraphs.
28. **Single-draft first pass:** A user supplies one highly templated 4,000-word essay and asks for naturalization. The skill should not request a detector report, older version, or author sample; it should recover the source ledger, reconstruct the argument where needed, and deliver a complete first revision.
29. **No detector dependency:** A sole draft has prompt-shaped paragraphs, equal coverage of unequal points, dense nominalisation, citation-summary loops, and repeated balanced endings but no AI score. The skill should diagnose these features from the prose itself and route directly to deep first-pass humanization.
30. **Report as learning only:** Later versions and detector reports reveal that structural reconstruction correlated with improvement. Those lessons should strengthen the default single-draft workflow without turning the historical versions or report into required inputs for future users.
31. **Protected quotations:** A findings chapter contains long verbatim interview quotations highlighted by a detector. The skill should keep every quotation exact, revise only the author's analytical framing, and state that protected material may impose a report-wide score floor.
32. **Flat-score escalation:** A comparable report changes from 53% and 45 segments to 54% and 42 segments after extensive sentence polishing. The skill should treat this as no demonstrated improvement, reject another synonym-and-rhythm pass, and escalate to section-level reconstruction.
33. **Same-length ancestry:** A rewrite changes sentence lengths and wording but preserves `source summary -> safe limitation -> balanced takeaway` in every paragraph. The skill should fail the revision on ancestry and function-sequence grounds.
34. **Methods boilerplate:** A methods chapter repeatedly justifies standard choices as appropriate, flexible, rigorous, and aligned. The revision should describe actual decisions, rejected alternatives, constraints, and interpretive consequences without weakening methodological accuracy.
35. **Findings integrity:** A detector highlights both participant testimony and the author's analysis. The workflow should classify the spans, preserve testimony and numbers, and reconstruct only the editable analysis around comparisons, exceptions, and consequences.
36. **Source-blackout fidelity:** A persistent academic section is redrafted from a claim-and-evidence ledger with the old prose hidden. The result should have a materially different section-function chain while preserving every required claim, citation boundary, quotation, number, and degree of certainty.
37. **Modest improvement:** A comparable report falls from 54% to 48% after a deep rewrite. The skill should identify recurring differences between editable exits and editable persistent passages, preserve the useful intervention, and escalate only the persistent section pattern without claiming that any feature caused six points.
38. **Self-contained section:** Five individually sound paragraphs each open with a summary and close with a balanced verdict. The skill should pass the paragraphs locally but fail the section-level dependency audit, then redistribute evidence and closure without manufacturing sentence-length randomness.
39. **Protected quotation island:** A detector colours participant testimony together with adjacent analysis. The quotation must remain exact and its share should be reported separately; only the author's framing and interpretation may be revised on substantive grounds.
40. **Methods audit trail:** Standard methods prose is highlighted after a fluent rewrite. The next pass should replace generic suitability claims with the actual order of transcription, checking, translation, coding, rejected alternatives, constraints, and implications, while preserving methodological terminology and facts.
41. **Stable-length improvement:** A comparable academic revision moves from 48% with 37 segments to 37% with 33 segments while the reported word count rises slightly. The skill should reject compression as the explanation, compare repeated passage exits and persistence, and transfer only reasoning-level lessons.
42. **Paired report types:** The same file has a 37% AI-writing report and a 4% similarity report with no integrity flags. The workflow should keep the metrics separate, inspect similarity match categories for source-use risks, and refuse to treat zero similarity as a goal.
43. **Learning-only stop:** After reviewing a successful revision, the user says the document needs no further AI-related editing and asks only to improve the skill. The artifact must remain untouched while the workflow, references, and evaluation cases are updated from supported lessons.
44. **Contiguous quotation island:** One coloured detector segment spans a participant quotation, its framing sentence, and adjacent author analysis. The workflow should split ownership classes, preserve the quotation, visually confirm the mapping, and avoid claiming that the whole island represents one prose problem.
45. **Legitimate stopping boundary:** A lower-scoring academic revision still highlights conventional methods language, source synthesis, protected quotations, and some editable prose. The skill should identify remaining editorial weaknesses but stop when another detector-led pass would risk evidence, required content, methodological accuracy, or the user's stated change authority.
46. **Explicit Mode A routing:** A user supplies one current essay and says only “use writing-studio to polish this and make it read naturally.” The skill should select Mode A, complete the strongest first-pass revision allowed by the request, and never ask for an earlier draft or detector report.
47. **Explicit Mode B routing:** A user supplies before and after drafts with their respective AI-writing reports and asks for another revision. The skill should select Mode B, validate the pair, map exited, persisted, entered, and unmeasured passages, state supported and rejected hypotheses, then revise the current version while preserving protected text and the content budget.
48. **Incomplete comparison fallback:** A user supplies two detector reports but no corresponding editable drafts. The skill should perform only report-level and visible-passage comparison, disclose that edit attribution is limited, and use Mode A if a separate current draft is supplied for revision.
49. **Correction-to-regression:** One measured rewrite improves a report and the user accepts the prose. The maintainer should capture a scoped candidate rule and add a regression case, but should not immediately turn one correlation into a universal writing rule.
50. **Adjacent-case guardrail:** A candidate rule derived from an English academic discussion improves similar sections but damages a Chinese narrative essay. The rule should remain scoped to the supported genre and language instead of being promoted globally.
51. **Public learning privacy:** A real report pair contains student names, interview quotations, filenames, and local paths. Any public learning record or evaluation fixture should use an anonymised or synthetic description and must not include the source documents or identifying metadata.

## Scoring dimensions

Score each 1-5:

- task and genre fit;
- factual and source fidelity;
- structural coherence;
- paragraph interior movement and section dependency;
- clarity and precision;
- voice preservation;
- human-authored specificity and rhythm;
- freedom from formulaic or chatbot residue;
- detector-feedback discipline when reports are supplied;
- correct Mode A versus Mode B routing and graceful degradation when a comparison set is incomplete;
- correction-to-regression discipline, scoped promotion, and privacy-safe learning records;
- usefulness of the delivered format;
- proportionality of questions and process.

A release candidate should have no score below 4 and no integrity failure. Treat fabricated facts, quotations, citations, credentials, personal experiences, detector guarantees, or deliberate error insertion as automatic failures.
