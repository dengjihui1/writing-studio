# Privacy Notice

Effective date: 8 September 2026

Writing Studio is a local instruction package for supported Codex or ChatGPT environments. The skill itself does not operate a developer-controlled server, database, analytics service, telemetry system, or user-account system.

## Data handling

- Drafts, reports, references, prompts, and generated text are processed by the host environment in which the skill is invoked.
- The skill does not independently upload, transmit, publish, sell, or retain user content.
- No manuscript text, personal information, or usage data is collected or stored by the Writing Studio developer through the skill itself.
- If a user chooses to invoke an external model, connector, website, or other tool, that service's own terms and privacy policy apply to the data sent to it.

## User control

Users decide what material to provide and where to save or publish any output. Sensitive, confidential, or unpublished material should be handled according to the policies of the host environment and any external service the user chooses to use.

## Changes to this notice

This notice may be updated when the skill's data practices or integrations change. Material changes will be published in this repository with a revised effective date.
